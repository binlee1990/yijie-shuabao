# 第三方资源声明

## Noto Serif SC

字体：Noto Serif SC，Regular/400。发行包来自 `@fontsource/noto-serif-sc`，为本作文字选择53个未修改的WOFF2切片。

版权所有者声明与完整许可：`Assets/fonts/OFL.txt`。采用 **SIL Open Font License 1.1**，随工程一并保留。字体不得单独出售，分发或修改须遵守该许可。单文件HTML内也嵌入了相同许可文本。

部分SVG占位中的文字已使用此字体转为轮廓；字体许可中说明，使用字体生成的文档并不因此必须采用同一许可。其余占位图形和提示音由本项目程序生成。

## 工程运行依赖

原生游戏依赖 Godot 4.5 .NET 与 .NET 8，不包含JavaScript运行时、远程API或CDN。字体适配使用fontTools进行WOFF到OTF容器转换；Godot、.NET SDK和开发工具二进制未包含在仓库中。

参考设计仓库与游戏并非本作素材来源。本项目未打包参考仓库源代码、商业游戏立绘、截图、音频或字体。
